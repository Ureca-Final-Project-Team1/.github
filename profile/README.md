## 프로젝트 배경

### 시장 분석

- **유휴 데이터의 구조적 소멸**
  - 무제한 요금제 확산으로 과잉 제공된 데이터의 자동 소멸 현상

- **비공식 거래의 신뢰성 문제**
  - 중고 커뮤니티 기반 거래의 사기 위험성과 법적 보호의 부재

- **공식 유통 채널의 부재**
  - 통신사 데이터 선물 기능의 낮은 사용성과 거래 수단으로서의 한계

### 개발 동기

- **데이터 유통 구조 설계의 필요성**
  - 소멸되는 데이터를 유통 가능한 자산으로 전환하기 위한 구조적 해결책의 필요

- **신뢰 기반 개인 간 거래 환경 조성**
  - 안전하고 공식적인 거래 구조를 통한 사용자 참여 유도
